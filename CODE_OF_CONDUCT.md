# Code of conduct

This project adopts the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
reproduced in full at that link rather than pasted here, so this file can never
drift from it.

Scope, in one line: technical disagreements are welcome and expected; personal
ones are not. This is a security-adjacent tool, so reviews routinely say
"that hook is wrong" — that is the work, not a slight.

Enforcement contact: open a private advisory the same way described in
[SECURITY.md](SECURITY.md).
